Política de privacidad

Everloop Uploader — Everloop Studios · Última actualización: 24 de noviembre de 2026

1. Qué es Everloop Uploader

Everloop Uploader es una aplicación de uso interno de Everloop Studios que se ejecuta en el equipo del propietario y utiliza la API de datos de YouTube (YouTube Data API v3) para subir videos al canal propio de Everloop Studios.

2. Datos a los que accede

Con la autorización expresa del titular de la cuenta mediante OAuth 2.0 de Google, la aplicación usa estos permisos:

  • youtube.upload: subir videos y sus metadatos (título, descripción, etiquetas, privacidad).
  • youtube.readonly: leer el nombre e identificador del canal para confirmar a qué canal se sube.

La aplicación no lee correos, contactos, historial de reproducción ni datos de otros usuarios.

3. Cómo se usan y almacenan

  • El token de acceso se guarda únicamente en el equipo local del propietario y nunca se envía a terceros.
  • Se conserva un registro local de los videos subidos (identificador, título y fecha).
  • No se venden, comparten ni transfieren datos a terceros, ni se usan para publicidad.

El uso de la información recibida de las API de Google cumple la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de uso limitado.

4. Servicios de Google

Al usar esta aplicación también se aplican las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

5. Revocar el acceso

El acceso puede revocarse en cualquier momento desde la configuración de seguridad de tu cuenta de Google. Al revocarlo, la aplicación deja de poder subir videos y el token local queda inservible.
